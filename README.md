## 🎯 課題とUX/UIアプローチ

### 1. 従来（LINE連絡のみ）の課題
- 長文テキストメッセージの連投により、日時・会場・振込先などの重要情報が埋もれる。
- テキストのみでは会場の雰囲気や規模感が分からず、参加の心理的ハードルが高くなる。
- 情報更新時に差分が分かりにくく、確認の手間が発生する。

### 2. 本プロジェクトでの解決アプローチ
- **情報の一元化 (Single Source of Truth)**: LINEからの誘導先としてWebサイトを設け、「サイトを見れば全て分かる」導線を設計。
- **安心感を与えるコンテンツ構成**: 会場（ホテルフランクス）の写真を掲載し、タイムテーブルやFAQを配置することで参加のイメージを可視化。
- **モバイルファースト＆レスポンシブ**: 通学・休憩時間のスマホ閲覧を想定したUI設計（アコーディオンメニューによる省スペース化、Google Maps埋め込みなど）。

## ✨ 業務効率化・バックオフィス自動化（GAS）

大量の参加者データ管理とメール連絡の工数を大幅に削減するため、Google Apps Scriptを用いた管理システムを自作・導入しました。

1. **入金ステータス連動型 自動メール送信**
   - スプレッドシート上の「振込済」「未振込」プルダウン操作に連動し、適切な案内メールを自動送信。
   - 送信結果（成功/エラー）をリアルタイムでシートへ記録し、手作業による連絡漏れ・ミスを防止。
2. **当日受付用の動的名簿抽出**
   - 受付の混雑を回避するため、事前振込者・当日支払者を分類した名簿を出力し、スムーズな受付体験を実現。

## 📈 データに基づく改善・施策（PDCA）

- **参加費の最適化 (10,000円 → 9,000円)**
  - 大学生層の金銭的負担感を踏まえ、より多くの人が参加できるよう価格改定を実施。
- **Webサイトのリニューアル & 写真追加**
  - 検討層向けにホテルHP・下見時の写真を拡充し、コンテンツの解像度を向上。
- **リマインド告知の最適化**
  - 申込数の推移データを可視化し、「締め切り1週間前」「1日前」などインパクトの大きいタイミングでLINE告知を実施。

## 💡 振り返りと学び

- **ユーザー視点（UX）と実装の統合**: ユーザーリサーチから課題を特定し、デザイン・実装・運用のトータル体験として落とし込む重要性を再認識しました。
